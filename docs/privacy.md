# 数据与隐私

异常识别、预览、复制、保存和本地搜索在本机运行，不引入遥测。插件读取用户触发操作的控制台快照，不自动读取项目源码或其他文件来构造AI上下文。

只有用户主动点击「询问AI」才会向 `https://api.deepseek.com/chat/completions` 发送当前稳定预览中所选的异常、主动勾选的前置日志、范围诊断及固定排错提示。日志自身可能包含令牌、路径、个人或业务信息；插件不保证自动脱敏，请在发送前核对/调整选区。保存草稿、打开记录和搜索不会自动发起AI请求。

DeepSeek API Key由用户在IDEA内填写，通过PasswordSafe保存，仅用于官方请求的认证头，不进入提示、项目配置、记录或日志。插件要求持久凭据存储可用，不替用户更改密码管理或安全设置。

客户端直连官方接口、禁止跟随重定向，不继承IDEA全局代理。请求可取消且不会自动重试；取消时服务商可能已经处理请求。收费、服务端处理与保留规则以用户与服务商的安排为准。AI回答只展示为内容，不自动执行代码或命令。

点击「保存记录」后，报错、主动附带的上下文及可选AI提问/回答写入来源项目的`.java-trace/issues/<UUID>.jti`。它们可能含敏感内容，建议在业务项目的`.gitignore`加入`.java-trace/`。旧版本机库只读入口不会自动迁移或删除旧数据。

本仓库的CI仅使用合成文本、合成凭据和本机环回HTTP服务。无需向GitHub Secrets填入DeepSeek Key，不把真实运行日志或问题记录上传为构建产物。
